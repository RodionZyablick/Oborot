# Оборот

Музыкальный плеер с диском, который можно крутить пальцем или мышью для перемотки.
Работает в браузере, ставится как приложение (PWA) на Android и ПК. Без сервера и аккаунтов.

## Возможности
- Своя библиотека: файлы или папка целиком, drag & drop, хранение в IndexedDB
- Диск реагирует на звук; три стиля (винил, кольцо, волна)
- Темы, акцентный цвет, скорость вращения
- Избранное, поиск, перемешивание, повтор
- Управление с экрана блокировки (Media Session), вибрация на телефоне
- Горячие клавиши: Space, ←/→, N, P

## Запуск
Открыть `index.html` через любой статический сервер (`npx serve` или `python3 -m http.server`).
Service Worker работает только по HTTPS или на localhost.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` / root. Откройте ссылку на телефоне и выберите «Установить приложение».
